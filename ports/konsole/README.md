## Install

Copy `Umber Calm.colorscheme` to ~/.local/share/konsole/ and choose it in Settings → Edit Current Profile → Appearance. Konsole color schemes have no cursor or selection keys: both are inherited from the profile (set the profile's custom cursor color to the palette's orange if you want the Umber Calm cursor).

## Uninstall

Choose another color scheme and delete the file.
